# zsh-autosetup

Auto-setup zsh, oh-my-zsh, some plugins, a theme I find useful, and zplug.

Works on macOS (Homebrew) and Debian/Ubuntu (apt). Safe to re-run.

```bash
git clone https://github.com/th2nhb1nh/zsh-autosetup.git
sudo chmod +x zsh-autosetup/zsh-autosetup.sh
zsh-autosetup/zsh-autosetup.sh
```
